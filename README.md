# TodoListo Automation

Automatización de TodoListo.uy para reducir tareas manuales y evitar gastar créditos innecesarios.

## Objetivo

Centralizar automatizaciones para conectar Google Sheets, WooCommerce y futuros canales de publicación.

## Flujo base

Google Sheets → TodoListo Automation → WooCommerce / publicaciones

## Principios

- Usar conectores directos cuando existan.
- Evitar usar Work para tareas repetitivas.
- Mantener costos en $0 o lo más bajos posible.
- Nunca guardar contraseñas, claves API ni tokens dentro del repositorio.

## Estado

Repositorio inicial creado y conectado correctamente con ChatGPT/GitHub.
